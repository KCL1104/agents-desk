## Overall Impression

這是一個把自己的哲學執行到 CSS 註解層級的介面 —— 狀態語言、後果文法、誠實原則在程式碼裡自我辯護。核心 triage 迴圈(⌘E、⌘K 收件匣、armed merge)是鍵盤原生的,而且情緒設計罕見地被認真做了(yolo 在選擇時警告、之後全程佩章;merged 獨佔顏色)。最大的單一機會:**旗艦表面(inspector、忙碌卡片)的能力增長快過版面的分層**,以及**核心表面(終端)對螢幕閱讀器完全沉默**。

## What's Working

1. **完整自創的狀態語言,通過截圖測試**:3px 事件邊、形狀編碼點、breath/shimmer 對、衍生 merged 色 —— 全部在碼內帶理由與 pragma 自衛;board.en.png 一眼可讀。
2. **無例外的後果文法**:兩擊 armed 按鈕自我改名點名將發生的事、琥珀=變異/玫瑰=刪除、4s/7s 依標籤長度調校、每扇打字門都有 dirty guard。找不到一處多餘確認。
3. **文案是設計材料**:雙語目錄用論證代替標籤 ——「no status signal」是免責不是狀態、每個拒絕附完整理由、標點連接詞進目錄讓 aria-label 永不混語。

## Priority Issues

**[P1] 核心表面對螢幕閱讀器 100% 沉默** — xterm 建構無 screenReaderMode(repo 全域 0 命中、無設定開關)且走 WebGL canvas(TerminalView.tsx:59-74, 186-210)。aria-live 把 Sam 召喚到一個他讀不到的 pane —— 授權提示(哪個指令、哪個檔案)是 triage 迴圈的中心行為,卻需要明眼協助。周邊還有:yolo/accept 模式徽章不在卡片 aria-label 裡(Board.tsx:487, 532-540)——「安靜的全自動看起來像普通監督」正是碼註自己說最糟的情況;sidebar 列動作的可及名是字形('✓'、'✕',SessionList.tsx:188-208)。
**Fix**:加 screenReaderMode 設定開關(xterm 原生支援,degrade 是尺寸行為非重繪)、把 mode 徽章寫進 aria-label、字形按鈕補 aria-label。**建議指令:/impeccable audit**

**[P1] Inspector 同時疊 8 個帶,旗艦決策面違反自家 ≤4 規則** — tabs、meta、5+ 工具 chip、queued banner、compare row、diff summary、diff、review composer、finish footer(AttemptInspector.tsx:296-675;inspector.en.png 可見)。工具 chip 列(shell+N scripts+Checkpoint+Preview+Park)與 finish footer 視覺競爭。
**Fix**:分層 —— meta+diff+finish 常駐;工具 chips 收成一個「Worktree」群或 overflow;讓靜止帶數 ≤5。**建議指令:/impeccable distill**

**[P1] 停止狀態卡片五顆 footer 按鈕,正好在重啟後每張卡都如此** — Resume、Park、Inspect、Switch agent、Delete(Board.tsx:651-737)。90% 的答案是 Resume,其他四顆稀釋它。
**Fix**:Resume primary、Inspect secondary;Park/Switch 降級為 hover/focus-within 顯示(sidebar 列已立此模式);Delete 獨留右側。**建議指令:/impeccable quieter**

**[P1] create→start 是鍵盤迴圈的斷點** — palette 選 backlog 卡只切視圖、focus 留在 <body>(CommandPalette.tsx:77-81);建卡後對話框關閉即棄置(App.tsx:756-770);兩個建立對話框都沒有 ⌘Enter(與 review composer 自家慣例不一致);'new-card' 無直接和弦(actions.ts:50 keys:null)。Alex 的結論:「這一段我伸手拿滑鼠」。
**Fix**:palette 選卡後 focus 落卡、建卡提供「Create & start」路徑或聚焦新卡、兩對話框補 ⌘Enter、給 new-card 一個直接和弦。**建議指令:/impeccable polish**

**[P2] 教學全部一次性、無再入口** — welcome 永不重現(無任何 reset 路徑)、四張 coach 退休後內容無處重讀、「finishing is final」這種最高後果的課只在第一次看 diff 時可讀一次;⌘K/⌘E/⌘/ 的發現全部鎖在「已經知道某個和弦」後面,chrome 上沒有任何可見的 '?' 或 ⌘K 提示。
**Fix**:見下方 onboard 提案 2/3/5(welcome 可重開、第五張 coach、空牆鍵位卡)。**建議指令:/impeccable onboard(提案已備)**
