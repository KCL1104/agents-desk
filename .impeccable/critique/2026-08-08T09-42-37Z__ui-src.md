## Design Specificity Verdict

**LLM 評估**:互動架構毫無疑問是為這個產品打造的 — 雙軸看板(人放的欄位 × agent 回報的狀態色)、卡片上的 worktree/branch 資訊、⚡/✎ 權限徽章、wsl:// 主機徽章、拖曳分割的終端牆、被框成「注意力調度器」的並行上限,任何通用 admin 模板都穿不上這件衣服。微文案是最強的特異性訊號:誠實(「參數慣例我們沒有實測過」)、講清楚影響範圍而不是打官腔。視覺皮膚本身是「稱職但通用」的 Tokyo-Night 暗色(#7aa2f7 標準 accent、8px 圓角卡片)— 對 Operate 介面而言剋制是對的,但產品的身份目前完全活在結構和文字裡,不在任何一顆像素上。

**Deterministic scan**:CLI 掃出 2 筆(exit 2),皆為 side-tab 反模式:styles.css:300(.ov-card)與 :481(.board-card)的 3px 左邊框 — snippet 是中性 var(--line),但狀態 modifier 確實把同一條邊框塗成 warn/accent/ok,瀏覽器引擎在實際渲染確認。瀏覽器掃描另補:11px 內文(.row-detail、.board-card-activity、.ov-detail)、10px 功能文字(.tab-badge「⚠1」、.pane-agent「claude」)低於 11px 下限、10–15px 的扁平字級階層(最大:最小僅 1.5:1)。marquee 與 gradient-text 為 detector 自我掃描 artifact,已剔除。main.main 對絕對定位子元素的 overflow clip 值得留意(可能剪掉未來的 tooltip/popover)。

**兩份評估的交會**:detector 的 side-tab 警告撞上 A 最讚賞的設計 — 左邊框狀態色正是雙軸看板的脊椎。這是「規則 vs 刻意設計」的典型衝突,交由使用者裁決。detector 的小字發現則支持 A 的可讀性扣分,兩邊互相印證。

## Overall Impression

骨架一流、神經末梢受傷。產品思考(雙軸看板、誠實文案、剋制用色)遠超同類工具,但核心迴圈的最後一哩 — 「agent 等你」的那一下點擊 — 壞掉了;鍵盤與輔助技術完全進不了主要介面;破壞性操作裸奔。這些都是 harden 級的修補,不是 redesign。最大的單一機會:把「等你」的訊號接到真正的畫面切換與 OS 通知上,讓產品兌現「你可以走開」的承諾。

## What's Working

- 雙軸看板模型是原創的產品思考:欄位是人放的、左邊框與 dot 是 agent 現在的狀態、agent 永遠不會動你的卡片。needs-you 卡(暖色 #1e1a12 底、2.4s 呼吸、⚠ 前綴、reduced-motion 靜態 fallback)在一整面終端牆裡一眼可尋。
- 微文案是開發工具裡的頂級水準(兩種語言都是):承認沒實測過別家 CLI 的參數、講明 yolo 的確切影響範圍、保證捨棄的變更會被凍結保留。這是建立信任的文案,不是填空。
- 有紀律的視覺剋制:單一 accent、顏色只表狀態、拖曳目標只在拖曳中出現、fg-dim 在三層背景上都有 6.0–6.7:1 — 核心文字色盤真正 AA-safe。

## Priority Issues

- **[P1] 「⚠ N 個等你」banner 與 sidebar row 從看板/總覽點擊後是死路** — App.tsx 的裸 onSelect() 把 session 放進(隱藏的)終端 layout 卻不 setView('terminal')。為什麼重要:這是核心迴圈的峰值時刻,點了沒反應讀起來像 app 壞掉。修法:banner 與 row 的點擊改走 onOpen()(已存在,onSelect + setView)。→ /impeccable harden
- **[P1] 鍵盤/輔助技術無法操作主要介面** — session row 是不可聚焦的 div、board card 是不可聚焦的 article、diff 行留言是 span onClick(皆實測);而 opacity:0 的隱藏鈕反而吃 tab focus(焦點落在看不見的控制項上,WCAG 2.4.7 fail)。修法:role="button" + tabIndex + Enter/Space;:focus-within 顯示隱藏操作鈕;:focus-visible outline token;modal 加 role="dialog" + aria-modal + focus trap。→ /impeccable harden
- **[P1] 破壞性與有損操作零防護** — 卡片 ✕ 一鍵刪除;髒對話框 backdrop 誤點丟輸入;Escape 全域無效。修法:刪除加確認或 5s undo toast;髒表單抑制 backdrop 關閉;共用 modal 包裝加 Escape。→ /impeccable harden
- **[P2] Env 面板 profile 列視覺回歸(上一輪 polish 引入)** — 全域 select{width:100%} + .profile-row select{flex:none} 讓 agent 下拉吃掉整行,args 輸入框被壓成 ~10px。修法:.profile-row select { width: auto }(或 flex-basis 固定)。→ /impeccable polish
- **[P2] opacity 疊加把文字壓到 AA 以下** — .row-elapsed(fg-dim × 0.7 ≈ 3.8:1 @11px)、.board-card[data-live='finished'] 0.62、.ov-card.exited 0.65 連內部按鈕一起變淡。修法:用明確的 faint token 取代容器 opacity,已結束卡片改用背景/邊框降調,文字與按鈕維持全不透明。→ /impeccable polish
- **[P2] 10px 功能文字低於樓地板** — .tab-badge(⚠1)與 .pane-agent(claude)10px;整體字級 10–15px 過度壓縮。修法:功能文字下限 11px,考慮把階層拉開(如 11/12/13/15/17)。→ /impeccable typeset
